# LOLA terrain profile

`profiles/athena-im2.json` comes from NASA PGDA's [LDEM_80S_80MPP_ADJ.TIF](https://pgda.gsfc.nasa.gov/data/LOLA_20mpp/LDEM_80S_80MPP_ADJ.TIF), described on the [product page](https://pgda.gsfc.nasa.gov/products/90). This is an 80 m/pixel, south-polar stereographic LOLA DEM in DE421 `MOON_ME`. The GeoTIFF's CRS gives a 1,737,400 m spherical radius; pixel values are surface height in metres above that radius. The profile is about 19 KB. No DEM is used by the API or stored in Git.

Regenerate with `python -m backend.terrain.preprocess athena-im2`. GDAL reads a window of the remote cloud-optimized GeoTIFF. You can also pass `--dem /path/to/LDEM_80S_80MPP_ADJ.TIF` if the file is local. `--radius-km`, `--step`, and `--height-m` control the terrain radius, azimuth spacing, and instrument height. The checked-in profile uses 40 km, 0.5°, and an assumed 2 m instrument height. The first 160 m around the observer is excluded because the 80 m cells and reported site coordinates cannot resolve very local slopes.

The script reads the GeoTIFF CRS and pixel positions, transforms pixel centres back to lunar longitude/latitude, and puts the observer and terrain points on spheres of radius `datum_radius_m + DEM height`. It subtracts their 3D positions and projects the result onto local east, north, and up. This includes lunar curvature. A cell contributes to azimuth bins covered by its angular footprint; the highest angle per bin is saved. Missing DEM pixels within the requested radius cause preprocessing to fail. The JSON records the source, CRS, datum, site elevation, pixel scale, range, height, and peak distance for each bin.

NAIF's [DE440 lunar frame kernel](https://naif.jpl.nasa.gov/pub/naif/pds/pds4/clps/clps_spice/spice_kernels/fk/moon_de440_220930.tf) defines our `MOON_ME` alias as `MOON_ME_DE440_ME421`, aligned to DE421 `MOON_ME` within 3.071 × 10⁻⁷ radians (about 0.53 m on the Moon) over 2000–2040. We use the DEM coordinates as that close approximation and do not apply an invented rotation. The real landing coordinates are rounded to hundredths of a degree; local terrain results may change with a more precise site position. The 40 km profile omits possible blocking terrain beyond that range, and visibility uses the centre of the Sun or Earth rather than the disk edge. Odysseus has no profile because its reported location is close to the DEM's 80°S coverage edge.
